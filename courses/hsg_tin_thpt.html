Nền Tảng Competitive Programming & Kỹ Thuật Tối Ưu C++20

Trong các kỳ thi Học sinh giỏi Tin học THPT (từ cấp Trường, Tỉnh/Thành phố đến Quốc gia VOI), ngôn ngữ C++ luôn là sự lựa chọn số 1 nhờ tốc độ thực thi vượt trội và thư viện chuẩn STL (Standard Template Library) phong phú. Tuy nhiên, để giành trọn vẹn điểm số trong 180 phút, thí sinh phải làm chủ tốc độ vào/ra (Fast I/O), tư duy chặn tràn số và phân tích độ phức tạp thuật toán cực kỳ khắt khe.

Fast I/O & Xử Lý Tràn Số

Lệnh cin/cout mặc định đồng bộ với thư viện C nên rất chậm. Bắt buộc thêm cin.tie(NULL); ios_base::sync_with_stdio(false); và dùng \n thay cho endl. Với giá trị lên đến $10^{18}$, dùng long long; với phép nhân có kết quả vượt phạm vi long long nhưng nằm trong khoảng $\pm 1{,}7\times10^{38}$, có thể dùng __int128 (mở rộng GCC/Clang, không thuộc ISO C++20).

Quy Tắc Ước Lượng 1.0 Giây

Hệ thống chấm thi hiện đại (Themis, CMS, VNOJ, Codeforces) thực hiện được khoảng $10^7$–$10^8$ thao tác đơn giản / giây tùy máy chấm, ngôn ngữ và thao tác. Nhìn vào giới hạn $N$ để đoán độ phức tạp:
• $N \le 20 \rightarrow O(2^N)$ (còn $O(N!)$ chỉ khả thi với $N$ nhỏ hơn nhiều)$
• $N \le 500 \rightarrow O(N^3)$ | $N \le 5000 \rightarrow O(N^2)$
• $N \le 2\cdot 10^5 \rightarrow O(N \log N)$ | $N \le 10^7 \rightarrow O(N)$
• $N \le 10^{18} \rightarrow O(\log N)$ hoặc $O(1)$

Mảng Cộng Dồn (Prefix Sum) & Kỹ Thuật Hai Con Trỏ (Two Pointers)

Mảng cộng dồn (Prefix Sum), Mảng hiệu (Difference Array) và Hai con trỏ (Two Pointers / Sliding Window) là những những kỹ thuật nền tảng thường gặp trong các bài thi lập trình. Chúng biến đổi các thao tác tính toán từ độ phức tạp $O(N)$ hoặc $O(N^2)$ xuống chỉ còn $O(1)$ hoặc $O(N)$.

Kỹ thuật Công thức cốt lõi Thời gian tiền xử lý Độ phức tạp truy vấn
Prefix Sum 1D pref[i] = pref[i-1] + a[i]
sum(l, r) = pref[r] - pref[l-1]		 O(N) O(1)
Prefix Sum 2D pref[i][j] = pref[i-1][j] + pref[i][j-1] - pref[i-1][j-1] + a[i][j]
sum(x1,y1,x2,y2) = pref[x2][y2] - pref[x1-1][y2] - pref[x2][y1-1] + pref[x1-1][y1-1]		 O(N * M) O(1)
Difference Array (Mảng hiệu) Cộng đoạn [L, R] thêm V:
diff[L] += V; diff[R + 1] -= V;		 O(1) mỗi cập nhật O(N) khôi phục mảng sau Q truy vấn
Two Pointers (Hai con trỏ) Con trỏ L và R chỉ dịch chuyển một chiều (Monotonicity) O(N log N) nếu cần sort O(N) duyệt tổng thể
two_pointers_longest_subarray.cpp Đoạn con dài nhất có tổng $\le S$ (Các phần tử $a_i > 0$) 
#include <bits/stdc++.h>
using namespace std;

// Tìm độ dài đoạn con liên tiếp dài nhất có tổng <= S
int longestSubarraySumAtMostS(const vector<long long>& a, long long S) {
    int n = a.size();
    int l = 0, max_len = 0;
    long long cur_sum = 0;

    for (int r = 0; r < n; ++r) {
        cur_sum += a[r];
        // Thu hẹp cửa sổ khi tổng vượt quá S (tính đơn điệu vì a[i] > 0)
        while (l <= r && cur_sum > S) {
            cur_sum -= a[l];
            l++;
        }
        max_len = max(max_len, r - l + 1);
    }
    return max_len;
}

Tìm Kiếm Nhị Phân & Kỹ Thuật "Chặt Nhị Phân Kết Quả" (Binary Search the Answer)

Tìm kiếm nhị phân (Binary Search) không chỉ dùng để tìm phần tử trên mảng đã sắp xếp trong $O(log N)$. Trong các đề thi HSG Quốc gia và Olympic, kỹ thuật quyền năng nhất chính là "Chặt nhị phân kết quả" (Binary Search on Answer): chuyển đổi bài toán tối ưu (tìm giá trị nhỏ nhất hoặc lớn nhất) thành bài toán kiểm tra tính khả thi (Hàm kiểm tra check(val) trả về true/false).

Dấu hiệu nhận biết bài toán Chặt nhị phân kết quả:

  • Đề bài có cụm từ: "Tìm giá trị lớn nhất sao cho...", "Tìm chi phí nhỏ nhất để...", "Độ chênh lệch lớn nhất là nhỏ nhất (Minimax)".
  • Khoảng giá trị kết quả có thể xác định được chặn dưới $L$ và chặn trên $R$ (ví dụ: $1 \le ans \le 10^{18}$).
  • Tồn tại tính đơn điệu: Nếu giá trị $mid$ thỏa mãn điều kiện thì mọi giá trị $\le mid$ (hoặc $\ge mid$) cũng thỏa mãn.
  • Hàm check(mid) có thể tính toán nhanh bằng thuật toán tham lam (Greedy) trong $O(N)$. Tổng độ phức tạp sẽ là $O(N log(R - L))$.
binary_search_answer.cpp Chia mảng gồm các số không âm thành $K$ đoạn liên tiếp không rỗng ($1 \le K \le N$) sao cho tổng đoạn lớn nhất là nhỏ nhất 
#include <bits/stdc++.h>
using namespace std;

// Với a[i] >= 0, 1 <= K <= N; có thể tách thêm để được đúng K đoạn.
// Hàm kiểm tra: có thể chia mảng thành <= K đoạn mà mỗi đoạn có tổng <= max_sum?
bool check(long long max_sum, const vector<long long>& a, int k) {
    int segments = 1;
    long long cur = 0;
    for (long long x : a) {
        if (x > max_sum) return false; // Một phần tử đã vượt giới hạn
        if (cur + x > max_sum) {
            segments++;
            cur = x;
        } else {
            cur += x;
        }
    }
    return segments <= k;
}

long long solve(int n, int k, const vector<long long>& a) {
    long long low = *max_element(a.begin(), a.end());
    long long high = accumulate(a.begin(), a.end(), 0LL);
    long long ans = high;

    while (low <= high) {
        long long mid = low + (high - low) / 2;
        if (check(mid, a, k)) {
            ans = mid;         // Ghi nhận đáp án hợp lệ
            high = mid - 1;    // Thử tìm giá trị nhỏ hơn nữa
        } else {
            low = mid + 1;     // Bắt buộc tăng giới hạn tổng
        }
    }
    return ans;
}

Số Học & Lý Thuyết Số Trong Thi HSG (Number Theory & Math)

Số học là "mỏ điểm" trong hầu hết các đề thi HSG Tỉnh và Quốc gia. Các bài toán thường yêu cầu kết quả lấy dư theo modulo $10^9 + 7$ hoặc $998244353$. Thí sinh bắt buộc phải nhuần nhuyễn các thuật toán số học có độ phức tạp $O(log N)$ hoặc tiền xử lý $O(N)$ để trả lời truy vấn trong $O(1)$.

Lũy Thừa Nhị Phân & Nghịch Đảo Modulo

Tính $A^B \pmod M$ trong $O(\log B)$. Khi $M$ là số nguyên tố (như $10^9+7$) và $A$ không chia hết cho $M$, theo định lý Fermat nhỏ: $A^{M-1} \equiv 1 \pmod M$, do đó nghịch đảo modulo của $A$ là $A^{-1} \equiv A^{M-2} \pmod M$. Với $B$ không chia hết cho $M$, phép chia $(A / B) \pmod M$ được chuyển thành $(A \times B^{M-2}) \pmod M$.

Tổ Hợp $C_N^K$ & Sàng Số Nguyên Tố SPF

Tiền xử lý mảng giai thừa fact[i] và nghịch đảo giai thừa invFact[i] trong $O(N)$, với $N < M$ khi modulo nguyên tố $M$, cho phép tính $C_N^K = \frac{N!}{K!(N-K)!}$ trong $O(1)$ mỗi truy vấn. Sàng Smallest Prime Factor (SPF) giúp phân tích thừa số nguyên tố của bất kỳ số nào $\le 10^7$ trong $O(\log N)$.

math_combinatorics.cpp Lũy thừa nhanh & Tổ hợp $O(1)$ Modulo $10^9+7$ 
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e9 + 7;
const int MAXN = 1e6 + 5;
long long fact[MAXN], invFact[MAXN];

long long power(long long base, long long exp) {
    long long res = 1;
    base %= MOD;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % MOD;
        base = (base * base) % MOD;
        exp /= 2;
    }
    return res;
}

long long modInverse(long long n) {
    return power(n, MOD - 2); // Chỉ đúng nếu n % MOD != 0
}

void precompute() {
    fact[0] = 1;
    invFact[0] = 1;
    for (int i = 1; i < MAXN; i++) {
        fact[i] = (fact[i - 1] * i) % MOD;
    }
    invFact[MAXN - 1] = modInverse(fact[MAXN - 1]);
    for (int i = MAXN - 2; i >= 1; i--) {
        invFact[i] = (invFact[i + 1] * (i + 1)) % MOD;
    }
}

long long nCr(int n, int r) {
    if (r < 0 || r > n) return 0;
    if (n >= MAXN) throw out_of_range("n exceeds precomputed range");
    return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
}

Quy Hoạch Động Cơ Bản Đến Trung Cấp (Dynamic Programming - DP)

Quy hoạch động (DP) là nội dung chiếm tỷ trọng điểm số cao nhất trong các kỳ thi chọn học sinh giỏi. Bản chất của DP là phân rã bài toán lớn thành các bài toán con gối nhau (Overlapping Subproblems) và có cấu trúc con tối ưu (Optimal Substructure), lưu kết quả vào bảng để không bao giờ phải tính toán lại.

1. Dãy Con Tăng Dài Nhất (LIS)

Thuật toán $O(N^2)$ cơ bản nâng cấp lên $O(N log N)$ bằng mảng tail[] kết hợp lower_bound.

2. Bài Toán Ba Lô (0/1 Knapsack)

Duyệt trọng lượng từ $W$ ngược về $w_i$: dp[j] = max(dp[j], dp[j - w_i] + v_i) trong không gian $O(W)$.

3. Dãy Con Chung Dài Nhất (LCS)

So khớp chuỗi $S_1, S_2$ trong $O(N \times M)$. Tối ưu bộ nhớ về 2 dòng luân phiên hoặc chuyển về LIS nếu ký tự đôi một khác nhau.

lis_fast.cpp Longest Increasing Subsequence $O(N log N)$ chuẩn thi quốc gia 
#include <bits/stdc++.h>
using namespace std;

// Trả về độ dài dãy con tăng dài nhất với N <= 2*10^5
int lis(const vector<int>& a) {
    vector<int> tail; // tail[i] lưu phần tử kết thúc nhỏ nhất của dãy con tăng độ dài i + 1

    for (int x : a) {
        auto it = lower_bound(tail.begin(), tail.end(), x);
        if (it == tail.end()) {
            tail.push_back(x); // Tạo dãy con tăng có độ dài mới lớn hơn
        } else {
            *it = x;           // Cập nhật giá trị kết thúc nhỏ hơn tối ưu cho tương lai
        }
    }
    return tail.size();
}

Chuyên đề 6 • Thuật toán chuyên sâu

Quy Hoạch Động Nâng Cao (Bitmask, Tree DP & Digit DP)

Để đạt giải Nhất Tỉnh hoặc giải Quốc gia (VOI), thí sinh cần bứt phá ở các bài toán Quy hoạch động nâng cao. Dấu hiệu đặc trưng: giới hạn $N$ nhỏ ($N \le 20$) gợi ý Bitmask DP, dữ liệu dạng cây tự do gợi ý Tree DP, hoặc đếm số lượng số trong khoảng $[A, B]$ thỏa mãn tính chất gợi ý Digit DP.

Quy Hoạch Động Trạng Thái Bit (Bitmask DP)

Sử dụng các bit nhị phân $0$ và $1$ của một số nguyên biểu diễn tập hợp con của $N$ phần tử ($N \le 20$). Số trạng thái là $2^N$. Các thao tác bit: kiểm tra phần tử $i$ có trong mask: (mask >> i) & 1; thêm phần tử $i$: mask | (1 << i); tắt phần tử: mask & ~(1 << i). Điển hình: Bài toán người du lịch (TSP) $O(2^N \times N^2)$.

Quy Hoạch Động Trên Cây (Tree DP & Rerooting)

Thực hiện DFS duyệt cây từ dưới lên (Bottom-up). Trạng thái dp[u] được tính dựa trên kết quả của tất cả các nút con dp[v] của $u$. Kỹ thuật Rerooting DP (Quy hoạch động đổi gốc) giúp tính đáp án cho mọi đỉnh đóng vai trò là gốc cây trong thời gian tổng $O(N)$ thay vì $O(N^2)$.

Chuyên đề 8 • Đồ thị nâng cao & Cây

Đồ Thị Nâng Cao (Tarjan Khớp-Cầu, SCC & Tổ Tiên Chung LCA)

Các chuyên đề đồ thị nâng cao là thước đo phân hóa huy chương trong kỳ thi chọn Học sinh giỏi Quốc gia (VOI) và VNOI Cup. Hai thuật toán nổi bật nhất là Thuật toán Tarjan (tìm Khớp, Cầu, Thành phần liên thông mạnh SCC trong $O(V + E)$) và Nhảy nhị phân (Binary Lifting) tìm Tổ tiên chung gần nhất (LCA) trên cây trong $O(log N)$.

Tarjan: Cầu & Khớp (Bridges & Articulation Points)

Xây dựng DFS Tree và gán nhãn thời gian thăm tin[u] cùng giá trị low[u] (thời gian thăm nhỏ nhất của đỉnh mà từ con cháu của $u$ có thể đi tới qua cạnh ngược Back-edge). Cạnh $(u, v)$ là Cầu khi và chỉ khi low[v] > tin[u]. Đỉnh $u$ là Khớp khi $u$ là gốc có $\ge 2$ con độc lập, hoặc $u$ không là gốc và tồn tại con $v$ sao cho low[v] ≥ tin[u].

Nhảy Nhị Phân & LCA (Binary Lifting)

Khởi tạo bảng up[u][j] là tổ tiên thứ $2^j$ của đỉnh $u$: up[u][j] = up[up[u][j - 1]][j - 1] trong $O(N \log N)$. Để tìm LCA của $(u, v)$, trước hết nâng đỉnh sâu hơn lên cùng độ cao với đỉnh nông hơn, sau đó đồng thời nhảy các bước lũy thừa của 2 từ lớn đến nhỏ. Thời gian truy vấn mỗi cặp đỉnh chỉ mất $O(\log N)$.

Cấu Trúc Dữ Liệu Nâng Cao (Fenwick Tree, Segment Tree & Trie)

Nếu mảng cộng dồn chỉ hỗ trợ truy vấn nhanh khi mảng tĩnh, thì Cây Fenwick (Binary Indexed Tree - BIT) và Cây phân đoạn (Segment Tree / Interval Tree) cho phép cập nhật phần tử và truy vấn đoạn liên tục trong thời gian $O(log N)$. Đặc biệt, kỹ thuật Lazy Propagation (Cập nhật lười) là "chìa khóa vàng" giải các bài toán cập nhật đoạn và truy vấn đoạn trong đề thi VOI.

Cấu trúc Dung lượng bộ nhớ Cập nhật điểm / Truy vấn đoạn Cập nhật đoạn / Truy vấn đoạn Ưu điểm & Nhược điểm
Fenwick Tree (BIT) O(N) (1 mảng duy nhất) O(log N) O(log N) (cần 2 cây BIT) Cực kỳ ngắn gọn (chỉ ~10 dòng code), hằng số tốc độ siêu nhỏ; khó áp dụng cho phép toán không có tính khả nghịch.
Segment Tree thường O(4N) O(log N) O(N log N) nếu lặp từng điểm Đa năng: giải quyết được Max, Min, GCD, Tổng, Matrix Multi; code dài hơn BIT.

Trie (Cây tiền tố & Bitwise Trie) O(Tổng độ dài chuỗi) với bảng con truy cập O(1); bộ nhớ có thể O(số nút * Alphabet) O(|S|) thêm chuỗi O(31) tìm max XOR cặp số Tra cứu tiền tố từ điển, giải quyết bài toán XOR lớn nhất của 2 số trong mảng $O(31 \times N)$.
fenwick_tree.cpp Binary Indexed Tree (BIT) - Cập nhật điểm & Tính tổng tiền tố $O(log N)$ 
#include <bits/stdc++.h>
using namespace std;

struct FenwickTree {
    int n;
    vector<long long> bit;
    FenwickTree(int n) : n(n), bit(n + 1, 0) {}

    // Cộng thêm delta vào phần tử vị trí idx (1-indexed)
    void add(int idx, long long delta) {
        for (; idx <= n; idx += idx & (-idx)) {
            bit[idx] += delta;
        }
    }

    // Tính tổng các phần tử từ vị trí 1 đến idx
    long long query(int idx) {
        long long sum = 0;
        for (; idx > 0; idx -= idx & (-idx)) {
            sum += bit[idx];
        }
        return sum;
    }

    // Tính tổng đoạn [l, r]
    long long queryRange(int l, int r) {
        return query(r) - query(l - 1);
    }
};

Xử Lý Chuỗi, Hình Học Tọa Độ & Chiến Lược 180 Phút Phòng Thi

Băm Chuỗi Đa Thức (Double Rolling Hash)

Chuyển chuỗi thành mã băm tiền tố $hash[i] = (hash[i-1] \times B + s[i]) \pmod M$. Lấy mã băm đoạn con $[L, R]$ trong $O(1)$: $hash(L, R) = (hash[R] - hash[L-1] \times B^{R-L+1}) \pmod M$. Nên cân nhắc dùng hai hàm băm độc lập (ví dụ $M_1 = 10^9+7, M_2 = 10^9+9$) để giảm rủi ro đụng độ trong mô hình băm phù hợp; double hash không loại bỏ hoàn toàn đụng độ hay tấn công có chủ đích.

Hình Học: Tích Có Hướng (Cross Product)

Cho 3 điểm $A, B, C$. Tích có hướng $\vec{AB} \times \vec{AC} = (B_x - A_x)(C_y - A_y) - (B_y - A_y)(C_x - A_x)$. Nếu $> 0$: $C$ rẽ trái; $< 0$: $C$ rẽ phải; $= 0$: thẳng hàng. Đây là nền tảng xây dựng thuật toán Bao lồi (Monotone Chain / Graham Scan) trong $O(N \log N)$.

Bảng Đáp Án & Lời Giải Chi Tiết Cả 10 Chuyên Đề:
Câu 1: Đáp án A. ios_base::sync_with_stdio(false) ngắt kết nối đồng bộ giữa C buffer và C++ stream, kết hợp cin.tie(NULL) bỏ auto-flush giúp tốc độ đọc nhanh tương đương hoặc hơn scanf.
Câu 2: Đáp án A. Vì mảng toàn số nguyên dương, khi mở rộng con trỏ phải $R$ thì tổng luôn tăng, thu hẹp $L$ thì tổng giảm. Kỹ thuật Two Pointers cho phép mỗi phần tử vào/ra đúng 1 lần, đạt thời gian tuyến tính $O(N)$.
Câu 3: Đáp án A. Điều kiện tiên quyết để chặt nhị phân kết quả là tính đơn điệu (Monotonicity), chia không gian tìm kiếm thành 2 nửa rõ rệt: toàn FALSE và toàn TRUE.
Câu 4: Đáp án A. Theo định lý Fermat nhỏ, nếu $P$ là số nguyên tố và $\gcd(a, P) = 1$ thì $a^{P-1} \equiv 1 \pmod P \implies a^{-1} \equiv a^{P-2} \pmod P$.
Câu 5: Đáp án A. Duyệt ngược từ $W$ về $w_i$ để khi tính $DP[w]$, trạng thái $DP[w - w_i]$ được lấy từ bước trước (đồ vật thứ $i$ chưa được chọn). Nếu duyệt xuôi sẽ biến thành bài toán Knapsack vô hạn (Unbounded Knapsack).
Câu 6: Đáp án A. Với $N \le 20$, mảng $DP[1 \ll N][N]$ có $2^N \cdot N$ trạng thái. Mỗi trạng thái thử chuyển sang đỉnh tiếp theo trong $N$ đỉnh $\implies O(2^N \cdot N^2)$, khả thi với $N=20$ ($2^{20} \cdot 400 \approx 4 \cdot 10^8$ phép tính cơ bản).
Câu 7: Đáp án A. Dijkstra với binary heap / `priority_queue` duyệt qua mỗi cạnh tối đa 1 lần, mỗi lần đẩy vào queue tốn $O(\log V)$, tổng thời gian là $O((V + E) \log V)$.
Câu 8: Đáp án A. Cạnh $u \to v$ là cầu khi và chỉ khi $low[v] > num[u]$. Còn đối với khớp (articulation point), điều kiện là $low[v] \ge num[u]$.
Câu 9: Đáp án A. Lazy Propagation trì hoãn việc đẩy giá trị xuống các nút con cho đến khi thực sự cần truy cập, giúp cả hai thao tác cập nhật đoạn và truy vấn đoạn đều chỉ tốn $O(\log N)$.
Câu 10: Đáp án A. Băm modulo $2^{64}$ (dùng unsigned long long) rất dễ bị hack bởi thuật toán sinh xâu Thue-Morse. Chuẩn an toàn nhất trong thi VOI là băm kép (Double Hash) với 2 modulo nguyên tố $10^9+7$ và $10^9+9$.
